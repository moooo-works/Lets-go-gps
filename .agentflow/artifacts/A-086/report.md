# Pixel實機回歸結果

已完成：Pixel7Pro／Android17的12項情境全部通過，0失敗、0跳過，最後一批耗時95.529秒。受測流程未觀察到crash／ANR。這輪沒有修改產品程式，只新增裝置回歸測試。

| 情境 | 結果 |
|---|---|
| 單點啟動、停止、取得非mock位置 | 通過 |
| 10次啟動／停止 | 通過 |
| 5組快速停止／開始，之後可再正常啟動 | 通過 |
| 路線移動、暫停、續播、停止 | 通過 |
| 路線完成後停止 | 通過 |
| 跳點路線切換與停止 | 通過 |
| 探索移動與停止 | 通過 |
| 傳送探索換中心與停止 | 通過 |
| 真實搖桿視窗、原生觸控拖曳與停止 | 通過 |
| 回背景後仍有更新、通知停止 | 通過 |
| 撤銷mock權限、停止、恢復後再啟動 | 通過 |
| 短時熄屏後仍有更新、通知停止、解鎖後取得非mock位置 | 通過 |

每個模式都有實際注入的正向對照；正常停止後確認IDLE、服務銷毀、mock provider清除，並呼叫正式定位helper取得非mock位置。停止尚未完成時，過早的開始指令可能被拒絕；測試確認停止完成後可再次啟動，不代表每個提前指令都會被接受。

原App與APK保留，隔離測試套件已移除，沒有殘留mock provider。Health Connect實寫關閉，沒有更動付款權益、Cloud或安全鎖設定。

範圍限制：背景與熄屏各觀察3秒，不等於長時間Doze／OEM省電驗收；Samsung、正式簽章安裝、付款入口與Health Connect實寫仍未測。搖桿以本機controller的Pro fixture測視窗與控制流程，不能當成購買入口已驗收。各模式的服務intent與通知action為實際Android路徑，但沒有逐一重走所有畫面入口；底圖授權受限，完整圖磚渲染未驗。

獨立審查的兩個測試判斷缺口已修正，最後整批12項重驗通過，最終審查無剩餘阻擋。這讓本次修正的共用停止流程有更完整的實機證據，仍不能保證所有裝置零crash。
